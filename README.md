# Xiaohan Yu Academic Website

A responsive, bilingual academic website built with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Files

- `index.html` — main academic homepage
- `cv.html` — printable web CV
- `styles.css` — all visual styles and responsive layouts
- `script.js` — language toggle, dark mode, mobile navigation, and reveal effects
- `assets/favicon.svg` — site icon

## Personalize before publishing

1. Replace `replace-with-your-email@example.com` in `index.html` and `cv.html`.
2. Replace the `#` links for Google Scholar, GitHub, and LinkedIn.
3. Review project titles, descriptions, dates, and affiliation.
4. Add coauthors, paper PDFs, publication links, teaching, awards, and a headshot as desired.

## Publish free with GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then save.

The site will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Other easy hosts

The same folder can be dragged directly into Netlify Drop or deployed through Cloudflare Pages or Vercel as a static site.

## Local preview

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
